## How I work

- **Plan before apply.** Idempotent Terraform; every change goes through a reviewed `plan` before it touches a tenancy.
- **Blast radius first.** Compartments, NSGs and route tables are drawn so a mistake in one spoke stays in that spoke.
- **Cost is a design input.** Defined tags and cost-tracking go in on day one, not after the first invoice.
- **Docs are part of delivery.** Diagrams, runbooks and DR test notes ship with the change, or it isn't done.
